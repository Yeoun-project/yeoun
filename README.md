## <span id="1">📢 1. 서비스 소개</span>

누구나 깊이 있는 질문을 해보고 싶지만

지인에게 묻기 민망하거나 진지한 답변을 받기 어려웠던 경험,

한번쯤은 있으시죠?

**'여운'** 은 질문 하나, 답변 하나에도

가이드와 제한, 익명성을 더해

이 순간에 온전히 집중하며 **‘진짜 여운’을 남기도록 설계한 서비스**입니다.

단순한 Q&A가 아니라

하루에 하나씩 ‘의미 있는 질문’을 직접 하고, 답하며

자기성찰과 공감, 위로를 얻는 사용자 주도형 서비스입니다.
